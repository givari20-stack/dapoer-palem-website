# Dapoer Palem website

Production-ready website foundation for **Dapoer Palem — Inspired by Nature**.

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Quality checks

```bash
npm run lint
npm run typecheck
npm run build
```

The project uses Next.js App Router, TypeScript strict mode, Tailwind CSS v4,
and ESLint. See [`docs/architecture.md`](docs/architecture.md) for the planned
route structure and asset conventions.
